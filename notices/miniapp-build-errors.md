# 小程序构建错误记录

## WXSS 编译错误：`error at token *`

### 错误表现

微信开发者工具编译 `app.wxss` 时提示：

```text
[ WXSS 文件编译错误] ./app.wxss
error at token `*`
对应的错误样式规则：
.stack>*+*{margin-top:24rpx}
原因
微信小程序 WXSS 编译器不支持该规则中的通用选择器 *。
由于全局 app.wxss 编译失败，小程序页面会显示空白。此时即使 app.json 中的页面路径配置正确，也无法正常渲染。
解决方式
将通用选择器改成明确的 class 选择器，例如：
.stack-item {
  margin-top: 24rpx;
}
并给需要间距的子节点添加 stack-item class。
修复必须放在源样式中，然后重新构建小程序。不要只修改 dist 目录下的临时文件，否则下次构建会被覆盖。
后续构建检查
如果再次出现 error at token '*'，优先检查源样式和生成的 app.wxss 中是否存在以下选择器：
* {}

.class > * {}

.class > * + * {}
小程序 WXSS 中优先使用明确的元素选择器或 class 选择器。
构建完成后，在微信开发者工具中执行：
1. 清除文件缓存；
2. 重新编译；
3. 确认 Console 没有 WXSS 编译错误；
4. 确认首页能够正常显示。
