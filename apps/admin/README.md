# 游伴独立运营 Web

更新：2026-10-16。Vue 3 + TypeScript + Vite + Router + Pinia + Element Plus。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

访问 `http://127.0.0.1:5174`，后端先 migrate 并在127.0.0.1:8000运行；`/api`、`/media`、`/static` 由本地代理转发。人工测试统一使用 test-staff-01/02，密码保存在已忽略的本地文件，见 [固定测试账号](../../notices/固定测试账号与使用约定.md)。超级管理员用于维护和受限配置，不用于模拟普通客服。

## 功能与权限

- 运营概览，游戏／商品类型／商品／首页配置管理、封面上传与首页投放。
- 订单查询、人工建单（待付款／已付款待派单）；仅待付款且未付款的订单可编辑／删除；通用编辑／删除尚无请求版本冲突校验。已付款订单不能通过通用编辑绕过履约。
- 客服确认实际陪玩：校验同游戏、接单资格、预约冲突与版本；更换指定意向人选需协商并填写说明。开始服务／申请完成由实际陪玩在订单会话操作，完成需客户同意，后台显示进度。
- 陪玩申请审核及档案维护，关键操作审计。
- 客服会话：与用户和陪玩分别文字沟通；订单列表可联系用户／实际陪玩。未读、待回复筛选；客服团队共用已读状态，回复记录保留具体员工。
- 业务列表及只读订单详情显示期间每5秒自动刷新，编辑表单打开时不替换列表内容。
- 售后复核：展示用户申请理由、金额与复核说明；通过生成待退款单，驳回允许用户在原期限内重提；通过后不能重复申请。待执行退款可登记模拟成功／失败／未知。未妥善退款的已通过案件阻止结算。

## 结算批次与业务配置

结算批次保存符合条件订单的实收、退款、净收入、抽成和陪玩应得金额。当前输入数据库内部数字订单 ID（不是 GC 订单号）；要求已付款、已完成、过售后期限、有实际陪玩、无待处理或已通过待退款售后、无待退款／未知退款且未结算。它不会向任何账户转账，真实打款及核销待实现。

业务与客服配置包括抽成比例（2000基点=20%）、售后时限、可选微信／企业微信外部渠道。抽成下单固化，售后截止时间在客户确认完成时生成；改配置不回写已有快照或截止时间。普通员工可读，仅超级管理员可保存。站内客服可直接使用，不需要先配置外部渠道。

## 删除边界

未被引用的目录／首页记录可经确认删除，携带 version 并记录审计；被引用记录返回409，应使用下架／停用。订单仅允许受限的未付款记录删除，已付款记录不可硬删；不得依据历史P4说明删除已付款订单。

## 已知缺口与验证

已付款未开始取消退款有后端接口但无专用按钮；售后图片上传／查看、鉴权私有下载、失败退款重试与未知查单、细分员工分区权限仍待完善。当前 staff 权限较宽，不等同于完整客服角色隔离。

`pnpm type-check`、`pnpm test`、`pnpm build` 用于类型、4项接口测试及构建。两端联调结果和人工步骤见 [客服与履约联调](../../notices/客服互通与售后联调说明.md)。构建成功不替代多角色业务验收或微信真机验收；模拟退款及账面结算不代表真实资金流转。
