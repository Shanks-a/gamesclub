# 游伴独立运营 Web

Vue 3 + TypeScript + Vite + Router + Pinia + Element Plus。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

访问 http://127.0.0.1:5174，使用 Django createsuperuser 创建的管理员登录。后端需先迁移并在127.0.0.1:8000运行；/api、/media、/static 通过本地代理转发。

`pnpm type-check` 检查类型，`pnpm build` 构建。根目录《第三阶段完成度与联调手册.md》包含模块完成情况、接口契约、数据备份和手动验收步骤。

当前订单详情和日志详情采用只读结构化展示。页面构建通过不等同于浏览器交互、微信真机或 PostgreSQL 并发验收通过。
# 管理后台

## 删除记录

游戏分区、商品类型、商品和首页配置列表的“操作”列现在提供“删除”。删除前会弹出确认框，并携带当前 `version` 防止误删他人刚修改的记录。

- 未被业务引用的记录可以删除，并会写入操作日志。
- 已被订单、收藏、商品类型、游戏分区或首页配置引用的记录会返回 `409 DELETE_CONFLICT`，不会删除历史数据。
- 商品已有订单时不能删除，请使用“下架”；商品仍被首页配置引用时，请先删除或修改对应首页配置。
- 订单和操作日志没有删除按钮，历史业务记录只读保留。

删除按钮出现后，如果页面仍显示旧版本，请重新启动 5174 管理端或在浏览器执行强制刷新。
