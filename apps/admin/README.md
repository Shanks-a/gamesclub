# 游伴独立运营 Web

Vue 3 + TypeScript + Vite + Router + Pinia + Element Plus。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

访问 http://127.0.0.1:5174，使用 Django createsuperuser 创建的管理员登录。后端需先迁移并在127.0.0.1:8000运行；/api、/media、/static 通过本地代理转发。

`pnpm type-check` 检查类型，`pnpm build` 构建。根目录《第三阶段完成度与联调手册.md》包含模块完成情况、接口契约、数据备份和手动验收步骤。

## 功能模块

- **运营概览**：商品/订单总数与各状态统计。
- **游戏分区 / 商品类型 / 商品管理**：增删改查、上下架、图片上传。
- **首页配置**：轮播 / 特价 / 人气展示位管理。
- **订单查询**：分页列表 + 搜索/筛选，**新增 / 编辑 / 删除 / 派单**。
  - 新增：选客户、商品、数量、预约日期/时段、订单状态、付款状态、陪玩。
  - 编辑：改任意字段，改商品或数量会自动重算金额与快照。
  - 删除：二次确认，连带清理支付记录与状态历史。
  - 派单：仅在订单「待派单」状态显示，指定接单中的陪玩。
- **陪玩申请**：审核入驻申请（通过 / 驳回）。
- **陪玩档案**：查看档案、切换接单开关。
- **操作日志**：关键操作审计记录。

订单详情和日志详情采用只读结构化展示。

## 删除记录

游戏分区、商品类型、商品和首页配置列表的“操作”列提供“删除”。删除前会弹出确认框，并携带当前 `version` 防止误删他人刚修改的记录。

- 未被业务引用的记录可以删除，并会写入操作日志。
- 已被订单、收藏、商品类型、游戏分区或首页配置引用的记录会返回 `409 DELETE_CONFLICT`，不会删除历史数据。
- 商品已有订单时不能删除，请使用“下架”；商品仍被首页配置引用时，请先删除或修改对应首页配置。
- 订单可通过“删除”按钮删除（区别于上面受保护的目录/商品记录）；订单和操作日志无版本乐观锁，删除前请确认。

删除按钮出现后，如果页面仍显示旧版本，请重新启动 5174 管理端或在浏览器执行强制刷新。

页面构建通过不等同于浏览器交互、微信真机或 PostgreSQL 并发验收通过。
